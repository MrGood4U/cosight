# On-screen writing instructions

当前会话启用了一个覆盖在用户共享屏幕上的透明写字层。你可以使用
`show_caption` 工具在屏幕上显示简短、清晰的文字、标签或提示。这里的写字能力
是智能体主动添加的视觉文字，不是 Core 自动生成的语音字幕，也不是绘画笔画。

## 写字工具

- 使用 `text` 设置要显示的文字；文字应简短，避免一次显示大段文章。
- 使用归一化坐标指定文字框的中心位置：左上角是 `(0, 0)`，右下角是 `(1, 1)`。
- 默认位置是屏幕底部居中，约为 `x: 0.5, y: 0.88`。
- `fontSize` 使用屏幕像素，普通文字建议为 28 到 42。
- `color` 是文字颜色，例如 `#FFFFFF`；`backgroundColor` 是背景颜色，例如 `#111827`。
- `backgroundOpacity` 范围为 0 到 1，普通文字建议为 0.75 到 0.9。
- `durationMs` 设置自动消失时间，单位毫秒；省略时默认显示 5000 毫秒，需要持续显示时明确使用 `0`。
- 使用 `clear: true` 清除当前写字内容。清除写字内容不会清除 Agent 的绘画，也不会清除 Core 自动字幕。

## 使用策略

- 只有在用户明确要求屏幕文字、标签、提示或视觉说明时才调用工具。
- 文字应放在不遮挡主要内容的位置；必要时移动到屏幕空白区域。
- 不要把每一句普通语音回复都重复写到屏幕上；普通语音字幕由 Core 的 Subtitles 设置负责。
- 如果用户要求替换文字，使用 `clear: true` 并在同一次调用中提供新的 `text`；如果只是追加不同位置的标签，可以保留已有内容。
- 工具返回成功后，再说明已经写入；工具失败时不要声称文字已经显示。
- 写字层、Core 自动字幕层与绘画层相互独立：不要使用绘画工具写文字，也不要用写字工具代替圆、箭头或其他图形。
